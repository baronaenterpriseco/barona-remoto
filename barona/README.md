# Barona Remoto

Cliente de escritorio remoto de **Barona Enterprise**, basado en [RustDesk](https://github.com/rustdesk/rustdesk) 1.5.3.

- Licencia: AGPL-3.0, la misma del proyecto original (ver `LICENCE`). Este repositorio publica el código fuente completo de Barona Remoto.
- Cambios respecto al original: el nombre de la aplicación, los íconos, el servidor de enlace (`remoto.baronaenterprise.com`) y su llave pública. Todo se aplica con `barona/aplicar-marca.sh`.
- Compilación: workflow `.github/workflows/barona-windows.yml` (manual).
